## Setup

```bash
# Repository klonen
git clone git@github.com:subworx-io/CORSOEPHY.git
cd CORSOEPHY

# Abhängigkeiten installieren
npm install

# Umgebungsvariablen konfigurieren
cp .env.example .env
# .env mit echten Werten befüllen

# Entwicklungsserver starten
npm run dev
```
