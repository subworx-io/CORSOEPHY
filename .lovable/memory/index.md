# Project Memory — Corso

## Core
Corso = lokale Stadtbeobachtungs-App mit Dating-Ausgang. Stadtbeobachtung zuerst, Dating als Ausgang — diese Reihenfolge prägt jede Entscheidung.
🔒 Live-Kamera-Pflicht für Clips. NIEMALS Galerie-Upload-Pfad, keine Filter, keine Beauty-Effekte, kein Schnitt innerhalb eines Clips.
🔒 Follower-/Reaktions-Zahlen sind für andere unsichtbar. Eigene Zahl ist privat (wie Kontostand). Keine öffentlichen Leaderboards oder Follower-Listen.
🔒 Stadt-Story um 20:00 fix; Teilnahme nur mit Pro-Clip-Einwilligungs-Toggle. Keine Reaktions-/Follower-Zahlen während der Stadt-Story sichtbar.
Publikum verfällt nach 24h. Clips leben 72h. Alles tagesseitige verfällt um Mitternacht.
Chat ist verdient: erst nach 3–4 Runden gegenseitigem Moment-Austausch, niemals als Startpunkt (Anti-Tinder).
Rampenlicht-Auswahl GEDÄMPFT: Follower erhöhen Chance mit abnehmendem Grenznutzen + Grundchance > 0 für jeden aktiven Clip.
🔒 Monetization verboten: Publikum-Verfall verlängern, "wer folgt"-Einblick, Rampenlicht-Chance/Reichweite kaufen. Nur Membership + Konsum-Consumables.
UX-Prinzip: Promenade zuerst (Stadt/Kollektiv), Kabine danach (Profil/Privat).
Pilot-Stadt Düsseldorf, junge Erwachsene 20–32. Sprache: Deutsch.
Vollständiges PRD in docs/PRD.md — bei Konflikt gewinnt das PRD.
