# Project Memory — Corso

## Core
Corso = lokale Stadtbeobachtungs-App mit Dating-Ausgang. Stadtbeobachtung zuerst, Dating als Ausgang — diese Reihenfolge prägt jede Entscheidung.
🔒 Live-Kamera-Pflicht für Momente (Foto + Video). NIEMALS Galerie-Upload-Pfad, keine Filter, keine Beauty-Effekte, kein Schnitt innerhalb eines Clips. Einzige, physisch getrennte Ausnahme: Medien im privaten Circle-Chat.
🔒 Follower-/Reaktions-Zahlen sind für andere unsichtbar. Eigene Zahl ist privat (wie Kontostand). Keine öffentlichen Leaderboards oder Follower-Listen.
🔒 Stadt Corso läuft rund um die Uhr: feste Plätze (Default 10), eine Belegung endet mit den 24h ihres Moments, der nächste rückt serverseitig nach. Kein 21-Uhr-Reset, kein täglicher Prompt (beides seit 9. Sep 2026 abgeschafft). Teilnahme nur mit Pro-Moment-Einwilligung. Keine Reaktions-/Follower-Zahlen im Stadt Corso.
Kein stadtweiter Reset: jeder Moment lebt 24h ab Upload, jeder Follow 24h ab dem (Re-)Follow, Erneuern ab 12h. Mehrere lebende Momente pro Person erlaubt; die Momente einer Person werden direkt auf der Kachel durchgeblättert.
Chat ist verdient: lebt nur im Circle, der nach 5 Tagen gegenseitigen Folgens entsteht (Schwelle unsichtbar) oder per persönlichem Einladungs-Link — niemals als Startpunkt (Anti-Tinder).
Rampenlicht-Auswahl GEDÄMPFT: Follower erhöhen Chance mit abnehmendem Grenznutzen + Grundchance > 0 für jeden aktiven Clip.
🔒 Monetization verboten: Publikum-Verfall verlängern, "wer folgt"-Einblick, Rampenlicht-Chance/Reichweite kaufen. Nur Membership + Konsum-Consumables.
UX-Prinzip: Promenade zuerst (Stadt/Kollektiv), Kabine danach (Profil/Privat).
Pilot-Stadt Düsseldorf, junge Erwachsene 20–32. Sprache: Deutsch.
Pilot läuft als PWA (kein Telegram). Zuerst gratis Freundes-Pilot (misst nur, ob der Loop zieht), danach zahlender Fremden-Pilot (€9).
Bau-Reihenfolge: Phase 0 (Backend-Fundament) blockt alles → Phase 1 (Konsum-Loop echt) → Phase 2 (Pilot-Härtung) → Phase 3 (Dating-Ausgang). Details in docs/ROADMAP.md.
Vollständiges PRD in docs/PRD.md — bei Konflikt gewinnt das PRD.
